# Import and Export

## Importing

Nimbus can import from Markdown files, Evernote (`.enex`), Notion (Markdown & CSV export zip) and OneNote.
Go to **Settings → Import**. Individual files up to **200 MB** are supported; larger archives must be split.

## Exporting

- A single note can be exported as Markdown, PDF or HTML from the note's **⋯** menu.
- A whole workspace can be exported by the owner as a zip of Markdown files with attachments,
  from **Settings → Workspace → Export**. The download link is emailed and stays valid for **7 days**.

## Attachments

Attachments up to 100 MB per file are supported on the Free plan and up to 1 GB per file on paid plans.
